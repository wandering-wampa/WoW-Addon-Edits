# WoW Addon Edits

Download and extract the ZIP, then manually place the addon folder in your WoW `Interface/AddOns` folder.

| Addon | What it does | Download |
| --- | --- | --- |
| [ConcentrationTracker_Edit](addons/ConcentrationTracker_Edit/README.md) | Tracks concentration across your alts, including time until full and local refill date/time, with a native Retail UI. | [**Download ZIP**](https://github.com/wandering-wampa/WoW-Addon-Edits/releases/latest/download/ConcentrationTracker_Edit.zip) |
| [AppearanceGuide_Edit](addons/AppearanceGuide_Edit/README.md) | Opens quest unlock guides from the Appearances tab. First guide: Tyr's Guard Bulwark. | [**Download ZIP**](https://github.com/wandering-wampa/WoW-Addon-Edits/releases/latest/download/AppearanceGuide_Edit.zip) |
